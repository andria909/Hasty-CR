# Проверка всех центральных клеток пушки

**В симуляторе центральная маска позволяет защищать раннего хога и перетягивать
шар с края. Позднюю реакцию выбор клетки не исправляет.** Ограничение остаётся
прежним:36 клеток x6–11,y18–23, пересечённых с механической допустимостью.

Полный перебор:8288 эпизодов,224 контекста, каждая допустимая центральная
клетка плюс контроль без карты. Все16 сочетаний живых башен принцесс, обе
линии, задержки1350/2025мс. Короли изначально живы и с полнымиHP; потеря
принцессы будит короля.4144 зеркальные пары дали одинаковые урон, перетяжку,
время первой цели на пушке и гибель короля.52 автоматических теста пройдены.

| Ситуация | Контекстов | Есть клетка для перетяжки | Есть клетка для защиты без урона башням |
|---|---:|---:|---:|
| Хог с моста, решение через1,5с | 64 | 64 | 64 |
| Хог с моста, решение через5,5с | 64 | 0 | 0 |
| Шар с крайней клетки, решение через1,5с | 64 | 64 | 48 |
| Хог из кармана, решение сразу | 32 | 32 | 32 |

К времени решения добавляется задержка команды. В позднем случае пушка ещё
может наносить урон и сокращать потери, однако хог уже не переключается на
неё в этих сценах. Переносить этот вывод на реальное удержание цели без
проверки нельзя. Карман также остаётся неподтверждённой геометрией симулятора.

Все16 случаев шара без защиты в ноль относятся к отсутствию обеих своих
башен принцесс. Одной пушки там недостаточно; сочетания с духом и заклинаниями
этот перебор не проверял. Даже для раннего хога в самом узком контексте
подошли только2 из36 клеток — разрешить центр не значит научить модель
правильно выбирать внутри него.

Числа показывают **существование удачной клетки, выбранной задним числом**,
а не процент успешной защиты модели. Каждый эпизод содержит одного
оплаченного атакующего без поддержки; пушка также оплачена. Нет занятых
клеток, сплит-пуша и сопутствующих заклинаний. Горизонт30с; долгосрочная польза
активации короля и контратаки не оценивается. Башни врага и задержки создают
коррелирующие контексты, поэтому224 не следует считать независимыми матчами.

Изменений физики, маски или награды по этому диагностическому перебору не
вносилось. Текущие обучения сохраняются. Следующий шаг по защите — проверить,
научились ли кандидаты реагировать до потери возможности перетяжки; отдельно
изучить комбинации против шара при отсутствии башен принцесс.
