# Переход длинных пилотов на полный бюджет

Все 8 профилей двух текущих серий прошли проверку фактических замороженных команд полного обучения: **4 096 000 шагов / 4000 обновлений**, заданный BC800, правильные частоты семейств и коэффициенты спеллов. Функция обучения остаётся идентичной исходному пакету. Это подготовка запуска, не завершённое большое обучение.

Каждая команда реально исполнялась на CPU с сокращённым бюджетом 16/32 шага: после восстановления совпали веса, оптимизатор и RNG. Затем сыграны 12 полных технических матчей на профиль, всего **96**. Проверены центральная пушка, текущая геометрия, бонус башен и расчёт штрафов по оплаченному эликсиру. Эти матчи не являются оценкой качества.

Общий отбор теперь принимает проверенные серии по 3 276 800 шагов и сохраняет отдельные требования к старым коротким сериям. Одинаковые профили с разным бюджетом не объединяются как повторы. Парный контроль берётся из закреплённого протокола; отбор требует отсутствия ухудшения общих и защитных побед на обоих seed, а также прежний порог каждого семейства. По одному прошедшему профилю из двух серий можно объединить в полную пару. Любой иной запрет продвижения сохраняется.

66 автоматических проверок прошли. Повторная независимая проверка всех трёх завершённых коротких серий (2 457 600 шагов) воспроизвела прежний отчёт отбора без изменений: 0 подходящих профилей. Новых победителей ещё нет.

Первый локальный прогон проверки остановился из-за общей папки демонстраций; для каждого профиля выделена отдельная папка, затем все 8 проверок завершились успешно. Исходная попытка сохранена. GPU-задания не менялись.

После завершения текущих пилотов: проверка весов → общий отбор 2–4 профилей → точная проверка сформированных полных пакетов → запуск полного бюджета → независимый test v4 и турнир. Эти локальные технические пакеты не допускаются к отправке как выбранные модели.
