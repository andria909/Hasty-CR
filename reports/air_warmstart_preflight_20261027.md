# Проверка обучения по успешным действиям

На48 собранных учебных состояниях исходная политика предпочитает другие действия: средний разрыв лучшего допустимого логита и лучшего успешного —197,37. Вероятности успешных действий в float32 округляются до нуля. Это наблюдение узкого набора состояний, не всей игры.

Реализована устойчивая цель: минус log суммы вероятностей всех проверенных успешных допустимых клеток. Она сохраняет ненулевой градиент даже при таком разрыве. Регуляризация KL к исходной политике и сохранение её value на тех же состояниях ограничивают локальное изменение; сохранность остальных навыков этим не доказана.

32 примера двух seed используются для обучения,16 примеров третьего seed — только для локальной проверки. Все связанные линии/задержки одного seed остаются в одной группе. Это не полный validation и не test.

Пять CPU-обновлений: ошибка TRAIN203,96→189,24; локальная проверка183,67→170,22. Успешный greedy-выбор пока0% в обеих группах. Три теста проверили градиент при исчезающе малой вероятности, отбрасывание незаконных меток и равноправие успешных клеток.

Новой принятой модели нет. Следующее испытание: короткий GPU warm start с несколькими силами KL, затем одинаковый бюджет PPO и проверка неизменённых полных матчей. Выбор по полному validation, а не только этим16 локальным примерам. Текущий bank-эксперимент не меняется.
