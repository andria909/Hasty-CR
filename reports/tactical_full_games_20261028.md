# Проверка тактических стартов на полных матчах

**24 TRAIN-матча завершились игровым исходом, без технических таймаутов.** Проверены шесть семейств соперников и четыре состояния своих башен принцесс. Использован прежний balanced без изменения весов; это проверка среды, не оценка нового кандидата.

Применены действующие коэффициенты pilot: перелив 0,3, ценность Fireball 0,25, потенциал резерва 0,1, штраф урона своим башням 6, добавление варваров 0,35, отражение сторон 0,5. Бонус урона башен 0,15 и штраф пустых заклинаний 0,1 фиксированы. Пушка только в центре, задержка 1350 мс, дополнительная блокировка слота 0.

| Проверка | Результат |
|---|---:|
| Конечный исход игры | 24/24 |
| Новые карты соперника после стартового пуша | 24/24 |
| Бой продолжился после гибели исходных тел стартового пуша | 21/24 |
| Награда совпала с пересчётом полного эпизода | 24/24 |
| Отклонённые команды / пушки вне центра | 0 / 0 |

«Исходные тела» здесь означает сохранённые ID юнитов на первом наблюдении; позже порождённые ими войска в этот счёт не входят. Это проверяет отсутствие завершения после первой волны, но не является самостоятельной метрикой успешной защиты.

Пересчёт награды использует изменение HP и перелива **после стартового наблюдения**, фактические исходы спеллов, накопленный shaping и конечную победу/поражение. Уже отсутствовавшие башни не штрафуются повторно. Отдельные 24 игры с базовыми коэффициентами тоже сохранены, но не смешиваются с этой таблицей.

Во время сверки полного профиля исправлена ошибка подготовки: при добавлении варваров рыцарь может исчезнуть из вражеской колоды. Для семейства swarm старт теперь использует присутствующую банду гоблинов; дополнительно проверяется принадлежность выбранной карты реальной колоде. Регрессионный тест с вероятностями варваров и отражения 100% подтверждает ровно восемь карт в руке и цикле, без добавления девятой.

36 профильных тестов прошли. Исходники: `sim/continuous_tactical_starts.py`, `scripts/attack/audit_tactical_full_games.py`. Артефакты: `tmp/tactical_full_games_20261028_full_profile/`. [Подтверждение и хэши](defense_plan/tactical_full_games_20261028.json).

Старты синтетические, четыре seed между семействами коррелированы. Эти игры не используются для выбора чекпойнта или заявления о реальном винрейте. Текущий GPU-pilot не менялся; следующий опыт ещё не запущен.
