# Покрытие карт текущего обучения

Извлечённый каталог `tmp/gamedata/csv_logic` отсутствует. Старые тесты эволюций/героев и полный набор колод ожидали этот источник; сейчас загрузчик использует публичный исторический набор. Поэтому9 одинаковых падений до/после исправления слотов не объясняются новой механикой руки.

Текущая среда использует `load_defense_assets`, а не только базовые `load_gamedata`/`load_spells`. Дополнительный загрузчик подключает поддерживаемые публичные заклинания.

| Проверка | Результат |
|---|---|
| Своя колода,6 семейств противника, Hunter/Valkyrie/Barbarians | Все32 карты доступны |
| Lightning в базовых загрузчиках | Отсутствует |
| Lightning в фактическом загрузчике среды | Доступен |
| Реальный вызов play_card и5 секунд симуляции | Списано6 эликсира, башне нанесено265 урона |
| Ожидаемый урон в загруженной таблице Lightning | 265 |
| Collector в текущих учебных колодах | Не используется |
| Collector в публичной таблице / старом тесте | 9000мс /13000мс |

Из этого не следует соответствие актуальному Clash Royale: проверены наличие данных и исполнение одного заклинания. Исторические публичные параметры могут расходиться с живой игрой. Не подменяли их числами из старого теста, не отключали падающие тесты и не меняли замороженные GPU-источники. Все характеристики Lightning и SHA публичных JSON сохранены в [отчёте](defense_plan/portable_curriculum_assets_20261027.json).

Новый тест проверяет именно загрузчик текущей учебной среды и оплаченный урон Lightning; прошёл. Проверку реальных параметров оставшихся карт нужно вести отдельно по данным текущего клиента/парсера.
