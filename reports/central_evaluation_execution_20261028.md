# Новый протокол оценки моделей

**Убрано расхождение настроек между сценарием и турниром.** Раньше duel был
жёстко привязан к225мс задержки и2100мс блокировки слота, а сценарный тест
получал часть настроек из текущих defaults среды. После изменения обучения
это могло незаметно сделать два вида оценки несовместимыми.

| Условие | Исторический протокол | Новый протокол |
|---|---:|---:|
| Задержка команды | 225мс (исполнение на тике250мс) | 1350мс |
| Решение модели | раз в250мс | раз в250мс |
| Дополнительная блокировка слота после исполнения | 2100мс | 0мс |
| Клетки пушки | механически допустимые | центральные, пересечённые с механической маской |

Ожидающая команда резервирует эликсир и блокирует только свой слот. Другие
слоты доступны. Одинаковые ограничения применяются к кандидатам, balanced,
strong и v25, на обеих сторонах поля. Отдельное время появления юнитов
сохранено. Награды обучения не используются как критерий победы в турнире.

Введён полный явный `execution` в новом blueprint и привязанном протоколе v2.
Каждый результат матча содержит этот контракт; проверка отвергает старые
строки без него, другую задержку, противоречивые настройки и пушку вне центра.
В дуэлях дополнительно сверяются число выполненных команд с принятыми и
отвергнутыми, минимум/максимум фактической задержки на50мс тиках.

Новые seed заранее записаны отдельно от прежнего test. Будущая полная оценка
сохраняет два набора соперников, все пары моделей и обе стороны; при2–4
кандидатах это4200–6300 матчей с тремя фиксированными базовыми моделями.
Привязка по умолчанию использует новый blueprint; старый доступен явно через
`--blueprint`. Старые6300 результатов и отправленные GPU-пакеты не изменены.
Новые цифры нельзя смешивать с историческими в одну турнирную таблицу.

Проверки:

- 84 автоматических теста: протокол, маски, параллельные слоты, резервирование,
  возобновление, упаковка, проверка результатов. Есть проверка стрессовой
  задержки2025мс, округляемой исполнителем до2050мс.
- Настоящие веса balanced (309 scalars) и v25 (306): четыре технических
  сценарных матча и две дуэли со сменой стороны. Пушка вне центра:0.
  В дуэлях выполнены324 команды, все через1350мс.
- Это технические development-seed, **не замер качества новой модели** и
  не основание для продвижения. Независимая полная оценка ещё не запущена.
